# Python Projects

This directory contains Python projects focused on programming fundamentals, problem-solving, and data analysis.

## Projects

### Sales Analysis
A Python project that processes sales transaction data stored in a CSV file.

**Files:**
- `datasales.py` — Reads sales data from a CSV file.
- `sales.py` — Performs sales calculations and generates insights.
- `transactions.csv` — Contains the sales transaction dataset.

**Features:**
- Reads structured data using Python's `csv` module.
- Calculates gross sales, discounts, and net sales.
- Calculates total units sold.
- Identifies the best-selling product by quantity.

## Requirements
- Python 3
- No external libraries required for the standard CSV functionality.

## How to Run
Run the main Python script from the project directory:

```bash
python sales.py
```

Make sure the CSV file path and Python imports are configured correctly.
