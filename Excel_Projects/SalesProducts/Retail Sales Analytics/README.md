# Retail Sales Analytics Dashboard | Excel

## Overview
An end-to-end retail sales analysis project built in Microsoft Excel to transform raw sales data into actionable business insights through data cleaning, KPI analysis, and an interactive dashboard.

## Key Features
- **Data Cleaning:** Validated sales records and checked data quality.
- **KPI Analysis:** Revenue, gross profit, profit margin, discounts, and average order value.
- **Sales Performance:** Actual sales vs. targets, with achievement rates.
- **Business Analysis:** Sales by product, category, region, channel, customer segment, and time.
- **Interactive Dashboard:** Filterable views for exploring sales performance.
- **Data Validation:** Cross-table checks and consistency testing.

## Key Insights
- Total net revenue: **268.65M**
- Gross profit: **51.06M**
- Gross profit margin: **19.01%**
- Sales target achievement: **198.6%**

*Metrics reflect the project's defined reporting rules and completed orders.*

## Tools

## Project Structure
- `Dashboard` — Interactive sales overview
- `Sales_Data` — Source sales records
- `Analysis_Data` — Prepared analytical dataset
- `Product_Analysis` — Product performance
- `Time_Analysis` — Sales trends over time
- `Dimension_Analysis` — Regional, channel, and customer analysis
- `Targets_vs_Actual` — Sales target performance

## Business Value
This project demonstrates how Excel can turn raw retail data into clear performance metrics, identify sales trends, evaluate profitability, and support data-driven business decisions.
